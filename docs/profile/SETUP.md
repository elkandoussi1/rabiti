# إعداد بروفايل أحمد على GitHub

التعريف والغلاف جاهزان في هذا المجلد. لم يُنشَر README في البروفايل الشخصي
بمجرد إضافته هنا؛ GitHub يعرضه بعد وضعه في مستودع عام باسم المستخدم نفسه.

1. أنشئ مستودعًا عامًا باسم `elkandoussi1` في حساب `elkandoussi1`.
2. ضع محتوى `docs/profile/README.md` في `README.md` في جذر ذلك المستودع.
   رابط الغلاف مطلق ويشير إلى الغلاف المنشور في مستودع رابطي؛ لا يلزم نقله.
3. في Edit profile استعمل الحقول التالية إن رغبت:

| الحقل | النص المقترح |
| --- | --- |
| Name | Ahmed El Kandoussi · أحمد القندوسي |
| Bio | أستاذ ومصمم ومطوّر أدوات تعليمية · Building practical tools for teachers and creators. |
| Location | Morocco |
| Website | https://elkandoussi1.github.io/rabiti/ |

4. ثبّت المشاريع المناسبة من Customize your pins. ابدأ برابطي ودفتر النصوص
   والحقيبة. لا تضف إحصاءات أو مهارات أو عناوين تواصل غير متحققة.
