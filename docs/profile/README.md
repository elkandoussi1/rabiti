### ما الذي أعمل عليه؟

أجمع بين التربية والتصميم والبرمجة لبناء أدوات تساعد الأساتذة وصنّاع المحتوى على تنظيم أعمالهم وتوفير وقتهم. أهتم بوضوح الواجهة، ودعم العربية، والعمل من الهاتف والحاسوب.

- **أدوات تعليمية:** تبسيط المهام المتكررة وإعداد الموارد المدرسية.
- **تصميم عملي:** دفاتر النصوص والتنقيط والعروض التقديمية.
- **تطبيقات ويب:** واجهات عربية متجاوبة وأدوات قابلة للاستخدام اليومي.

### أسلوبي في العمل

**مشكلة واضحة ← تجربة بسيطة ← اختبار فعلي ← تحسين مستمر**

أبدأ من حاجة عملية لدى الأستاذ أو المستخدم، ثم أعمل على تحويلها إلى أداة واضحة ومفيدة، مع الاهتمام بالتفاصيل العربية وتجربة الهاتف.
