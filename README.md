## ما هو رابطي؟

تطبيق ويب متجاوب لبناء صفحة شخصية أو واجهة متجر رقمي. تدير روابطك وصور
منتجاتك ووصفها من لوحة خاصة، ثم تنشرها على رابط ثابت للزبائن. يعمل على
الهاتف والحاسوب، ويمكن تثبيته كتطبيق ويب PWA.

## المميزات

| الميزة | الحالة |
| --- | --- |
| حسابات سحابية وتأكيد البريد واسترجاع كلمة المرور | متاحة عبر Supabase Auth |
| مسودة خاصة ورابط عام مستقل | متاحان؛ النشر منفصل عن الحفظ |
| صور ووصف كامل للمنتجات | واجهة عربية وإنجليزية وفرنسية |
| دفع وتسليم تلقائي | عبر منتج Gumroad المؤهل؛ يتطلب الإعداد لكل منتج |
| المشتريات السابقة بالأكواد | مدخل تنزيل مستقل؛ أزيلت خطوات الدفع وإثباته القديمة |
| تثبيت وتحديث التطبيق | فحص إصدار وحفظ المسودة قبل إعادة التحميل |
| تصدير واستيراد نسخة JSON | متاحان؛ تحفظ النسخة في مكان خاص |

## البيع التلقائي

1. أنشئ المنتج وارفع ملفه في حسابك على **Gumroad**، وأكمل متطلبات الحساب.
2. أضف رابط المنتج إلى رابطي، وطابق السعر والعملة مع صفحة Gumroad.
3. احفظ وانشر. يفتح زر الشراء صفحة الدفع الرسمية، ويتم التسليم لدى Gumroad.

المنتجات القديمة لا تملك رابط شراء تلقائيًا. تظهر في لوحة التحكم بحالة
«أضف رابط الشراء»، ويظهر للزائر أن الشراء غير متاح حتى إتمام الإعداد.
لا تُعرض نافذة الطلب والتحويل وإرسال الوصل القديمة.

لا تتزامن مبيعات Gumroad مع رابطي، ولا يُفعّل هذا الربط التحصيل المحلي بالدرهم
أو يضمن قبول البطاقات المغربية المحلية. راجع [دليل البيع](GUMROAD-SETUP.md)
للأهلية والرسوم. لم يُختبر دفع حقيقي نيابة عن صاحب المتجر.

## التشغيل والتطوير

واجهة التشغيل ملفات ثابتة؛ لا تحتاج إلى بناء. شغّل خادمًا محليًا:

```sh
python -m http.server 8080
```

افتح `http://localhost:8080/` أو `?local=1` للوضع المحلي. إعداد الاتصال في
`config.js` يستخدم عنوان المشروع والمفتاح العام فقط. راجع
[SETUP-AR.md](SETUP-AR.md) لإعداد قاعدة جديدة بالترتيب؛ لا تعِد تشغيل مخطط
الإنشاء على مشروع موجود.

لاختبارات التطوير استخدم Node.js 22:

```sh
npm ci
npm test
```

## بنية المشروع

| المسار | المسؤولية |
| --- | --- |
| `index.html` | المحرر وقوالب الصفحات المصدّرة |
| `cloud.js` | المصادقة والمسودة السحابية والنشر |
| `commerce-editor.js` و`commerce.css` | إعداد الشراء وإدارة المنتجات |
| `public.html` و`public.js` و`store-renderer.js` | صفحة الزبائن وتنقية البيانات والعرض |
| `app-update.js` و`sw.js` و`release.json` | التثبيت والتخزين المؤقت وفحص الإصدار |
| `supabase/` | المخطط والصلاحيات والنشر والتسليم السابق |
| `tests/` | اختبارات PostgreSQL/PGlite وواجهات jsdom |
| `docs/profile/` | تعريف GitHub وغلافه الجاهزان لمستودع البروفايل |

## الحماية والمساهمة

تفرض RLS ملكية المسودات. النشر يختار حقولًا عامة محددة ويستبعد مصادر التسليم
الخاصة والأكواد. صفحة الزبائن مستقلة عن المحرر. لا تضف مفتاح `service_role`
أو أي مفتاح سري إلى الواجهة.

راجع [SECURITY-STATUS.md](SECURITY-STATUS.md) و[TESTING.md](TESTING.md)
للنتائج وحدود الاختبار، و[CONTRIBUTING.md](CONTRIBUTING.md) للمساهمة،
و[THIRD-PARTY.txt](THIRD-PARTY.txt) للمكتبات وتراخيصها.
