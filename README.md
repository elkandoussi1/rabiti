# Rabiti — رابطي

محرر روابط ومنتجات مع وضع محلي ووضع متاجر سحابية اختياري.

**للتفعيل السحابي اقرأ [SETUP-AR.md](SETUP-AR.md).**
في الوضع السحابي تحصل على رابط `public.html?store=اسم-المتجر`، وتُنشر
تعديلاتك إليه من لوحة التحكم دون تصدير الموقع كل مرة.

يلزم مشروع Supabase وتطبيق `supabase/schema.sql` وإعداد القيم العامة في
`config.js`. الإعدادات الفارغة تبقي الوضع المحلي القديم.

احفظ نسخة JSON من بيانات الحساب المحلي قبل تفعيل السحابة؛ ثم استوردها
داخل الحساب السحابي. لا تُرحّل كلمات المرور أو الحسابات المحلية تلقائيًا.

التسليم المدفوع اليدوي يدعم أكوادًا يتحقق منها الخادم، وتفعيلًا لمتصفح واحد
مع إعادة التحميل بإيصال محفوظ فيه. اقرأ SETUP-AR.md لحدود نقل الجهاز والنسخ.
الدفع التلقائي والملفات الكبيرة وإدارة الاشتراكات ليست مكتملة في هذه المرحلة.

راجع [TESTING.md](TESTING.md) للاختبارات وحدودها، و[THIRD-PARTY.txt](THIRD-PARTY.txt)
لنسبة مكتبة Supabase وترخيصها.
